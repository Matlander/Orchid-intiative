# Orchid Initiative

Orchid Initiative works with communities in Busia, Uganda through fruit tree planting, practical agricultural learning, and opportunities for women and young people.

**Live website:** [matlander.github.io/Orchid-intiative](https://matlander.github.io/Orchid-intiative/)

This repository contains the website's HTML, CSS, JavaScript, and images. Start at `index.html` to explore the projects, gallery, ways to get involved, and the virtual tree-growing activity. The activity is a demonstration: tapping does not fund or plant a physical tree.

To preview the website locally, open `index.html` or serve this directory with a local static server. No build step is required.
